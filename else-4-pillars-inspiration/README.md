# else · 4-Pillars Inspiration

מחקר השראות ומתחרים שנוחת כ**לוח FigJam עם צילומי מסך אמיתיים מוטמעים** — לא רשימת לינקים. הסקיל חוקר נושא מ-4 זוויות שונות, כל אחת עונה על שאלה אחרת, ומסמן **פלואו אחד מנצח** ששווה ללמוד ממנו.

> A Claude Code skill (packaged as a plugin) that runs a structured, pain-grounded inspiration + competitor sweep and builds a FigJam board of real screenshots — each with a *what you see / why it's good for us* caption.

הסקיל **תמיד פותח בראיון קצר** (בממשק השאלות): על מה הפרויקט, מי הקהל, איזה מסך/דפוס, מובייל או ווב, **ומה ידוע על המשתמשים — הכאבים והמסע שלהם** (אפשר לתת לינק/ים למחקר או טקסט חופשי), ולאן לשים את הלוח.

## 🧭 איך זה עובד — ארבעת הפילרים

| # | פילר | השאלה שהוא עונה עליה | מקורות |
|---|------|----------------------|--------|
| 1 | **מתחרים ישירים** | איך מוצרים שפותרים בדיוק את הבעיה שלי, לאותו קהל, עושים את זה? | Mobbin + חיפוש רשת |
| 2 | **אפליקציות ענק** | אילו קונבנציות הקהל שלי *כבר מכיר* מהאפליקציות הגדולות — שאפשר לאמץ בלי עקומת למידה? | Mobbin (אפליקציות ענק) |
| 3 | **אקוסיסטם והשראות** | מי עוד — *לא בהכרח מתחרה* — פותר בעיה מבנית דומה בתחום סמוך? | Mobbin + רשת (תחומים סמוכים) |
| 4 | **טרנדים עיצוביים** | לאן הולך הכיוון הוויזואלי למוצר כזה? | Dribbble / Behance / Awwwards + Mobbin |

**הדגשים:**

- **הכאב הוא עדשת הבחירה.** ה"למה טוב לנו" של כל רפרנס נגזר מכאב/צורך/שלב-מסע אמיתי שעלה בראיון — לא שבח כללי. בלי מחקר, זה נכתב כ**השערה מסומנת**.
- **⭐ פלואו מנצח.** אם יש פלואו אחד בולט, הסקיל מושך את **הרצף המלא** (כמה מסכים, לא צילום בודד), מדביק אותו כסטריפ בראש הלוח, ומסביר את הגישה ולמה היא מתאימה. אחד בלבד.
- **מצב flows-only.** אם מבקשים *פלואים* — כל הפלט פלואים (רצפים), לא מסכים בודדים.
- **loop הרחבה.** בסוף, הסקיל מציע להרחיב עוד השראות — ואפשר לבחור לאילו פילרים (ריבוי-בחירה) או לכולם; כל סבב מתווסף כשורה חדשה.

## 🖼️ התוצר — פורמט הלוח

כל רפרנס על הלוח = **שלושה אלמנטים בטור**:

1. **כותרת** (⭐ על הבחירה הטובה ביותר בפילר)
2. **צילום מסך אמיתי**
3. **כיתוב אחד**: `מה רואים` (קריאה עובדתית) + `למה טוב לנו` (צמוד לכאב/מסע) + 🔗 מקור

ארבעה סקשנים (פילר לכל אחד), ולמעלה — סטריפ הפלואו המנצח.

## ⚙️ דרישות

הסקיל צריך גישה ל:
- **Mobbin MCP** — `search_screens` / `search_flows` (מקור צילומי המסך של מוצרים).
- **Figma MCP** — `upload_assets` / `use_figma` (בניית לוח ה-FigJam והטמעת התמונות).
- דפדפן (built-in או Chrome) לשוטים מ-Dribbble/Behance (אין להם MCP).

בלי Mobbin/Figma הסקיל עדיין מתכנן ומחקר, אבל לא יבנה את הלוח.
